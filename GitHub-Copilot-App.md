# Are there copilot skills to use in GitHub copilot to help with Power Point?

Yes, specialized toolkit skills and community repositories exist to help GitHub Copilot 
and related agent tools inspect, analyze, and build PowerPoint (.pptx) presentations. 

[1] (https://github.com/Sentry01/copilot-cli-skills/blob/main/powerpoint-toolkit/SKILL.md), 
[2] (https://techcommunity.microsoft.com/blog/azuredevcommunityblog/supercharge-your-dev-workflows-with-github-copilot-custom-skills/4510012)

## Available PowerPoint Skills & Toolkits

- PowerPoint Toolkit (`copilot-cli-skills`): 

Open-source skill sets available on GitHub—such as the PowerPoint Toolkit SKILL.md—allow GitHub Copilot CLI 
and agent modes to run local scripts that inspect deck structure, extract text, generate visual thumbnails, 
analyze design, and programmatically draft or edit presentations using Python tools like python-pptx. 

[1] (https://github.com/Sentry01/copilot-cli-skills/blob/main/powerpoint-toolkit/SKILL.md)

- Custom Agent Skills (`.github/skills/`): 

You can create or install Markdown instruction files (`SKILL.md`) paired with scripts into your repository's 
`.github/skills/` folder so GitHub Copilot Agent Mode can handle multi-step document generation workflows. 

[1] (https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/add-skills), 
[2] (https://techcommunity.microsoft.com/blog/azuredevcommunityblog/supercharge-your-dev-workflows-with-github-copilot-custom-skills/4510012)


## Distinction: GitHub Copilot vs. Microsoft 365 Copilot in PowerPoint

- GitHub Copilot handles code, markdown, and local file automation (like running scripts to build or parse .pptx files via developer libraries). 
[1] (https://techcommunity.microsoft.com/blog/azuredevcommunityblog/supercharge-your-dev-workflows-with-github-copilot-custom-skills/4510012), 
[2] (https://github.com/Sentry01/copilot-cli-skills/blob/main/powerpoint-toolkit/SKILL.md)

- Microsoft 365 Copilot in PowerPoint is the native in-app assistant inside the PowerPoint application itself. 
It supports its own built-in or custom document-level skill and template system managed directly inside the M365 Copilot in PowerPoint Skills
Panel rather than running through VS Code or the GitHub Copilot CLI. 

[1] (https://www.reddit.com/r/copilotstudio/comments/1uepdrw/copilot_building_powerpoint/),  
[2] (https://support.microsoft.com/en-us/powerpoint/copilot/copilot-in-powerpoint-skills)
