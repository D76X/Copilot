# Export all History from Perplexity

Perplexity does not offer a native, one-click bulk download button for all your conversation history 
directly from the user interface. 

However, you can export your data by: 

- submitting an official data request 
- using community-built automation scripts
- exporting threads individually.

1. Official Bulk Data Export (Easiest)

You can request a complete archive of your account data directly from Perplexity.
Go to the Perplexity Data Request Form.
Enter your account email address.
Select "Data Export" as the request type and submit.

You will receive an export package via email, which can take up to 30 days to process.

2. Bulk Export Using Automation Tools (For Local Archives)

If you want to grab your entire conversation history to store as organized Markdown or JSON files 
(ideal for apps like Obsidian), you can use community-built scripts:

[Perplexport](https://github.com/leonid-shevtsov/perplexport):

A popular Node.js script that logs into your account and downloads all conversations into Markdown or JSON files. 
You can access it on GitHub - leonid-shevtsov/perplexport.Perplexity 

AI Export Tool: 

Another Python/GitHub-based tool that extracts your threads and formats them into a semantically organized folder structure. 
Find it at GitHub - `simwai/perplexity-ai-export`.

3. Individual Thread Export (Manual)

If you only need to save specific threads rather than your entire history, you can export them individually 
on a case-by-case basis:Export by section: Hover over an AI response in a thread, click the export icon,
and download the information directly.Download as PDF/Markdown: Click the dedicated button at the top of a 
conversation and choose to export the entire thread as a PDF, DOCX, or Markdown file.Community Consensus: 
Many users suggest that using browser extensions like the Save My Chatbot Extension on Chrome is the fastest 
way to extract and format specific threads into Markdown.
